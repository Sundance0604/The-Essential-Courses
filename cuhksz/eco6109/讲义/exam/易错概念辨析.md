# 易错概念辨析

| 容易混淆 | 应如何区分 |
|---|---|
| 每股价格与投资表现 | 价格未调整时可能受拆股、分红影响；比较投资表现应定义总收益 |
| 总收益倍数与净收益率 | $G=1+R$，$G=1.05$ 表示净赚 $5\%$ |
| 算术平均与复利增长 | 前者平均单期收益；后者由财富连乘决定 |
| 对数收益与简单收益 | 小收益时近似；资产加权与时间加总规则不同 |
| 年化收益率与月度持有收益 | 月度观测不改变其报价期限，不能未经转换相减 |
| 波动率与标准误 | 单期结果波动与参数估计精度 |
| 零相关与独立 | 前者只排除线性共变，后者约束全部联合分布 |
| VaR 与最大损失 | 分位阈值与分布最坏值不同；VaR 不描述超越损失大小 |
| 样本平均为正与显著为正 | 后者还取决于标准误、样本及检验方式 |
| p 值与原假设概率 | p 值以原假设和模型为条件，不是原假设的后验概率 |
| 不拒绝与证明相等 | 检验功效不足也会不拒绝 |
| 显著性与经济重要性 | 统计精度不等于收益大小、风险调整表现或可执行性 |
| 同期拟合与事前预测 | 预测只能使用当时已知信息 |
| 高 $R^2$ 与预测准确 | 前者是样本内拟合，后者需独立后续测试与基准 |
| β 与总风险 | β 衡量市场共同暴露，总方差还含残差变化 |
| 跑赢市场与 α | $\bar D=\hat\alpha+(\hat\beta-1)\bar X$ |
| CAPM 与市场回归 | 投影总可定义；CAPM 加入 α 为零的定价限制 |
| 单因子 α 与投资能力 | 遗漏因子可能进入截距，基准不完整会影响解释 |
| 因子与特征 | SMB 是组合收益差，市值是公司特征，对 SMB 的 β 是暴露 |
| 时间序列 β 与截面 γ | 前者比较同一资产不同月份，后者比较同月不同股票 |
| 零净权重与无风险 | $\mathbf1'w=0$ 不推出 $w'\Sigma w=0$ |
| HAC 与“修复一切” | HAC 修正特定条件下的协方差估计，不能修复内生性、单位根或泄漏 |
| 严平稳与弱平稳 | 全部有限维分布与一二阶矩结构 |
| 平稳与遍历 | 平稳不足以保证一条路径样本平均等于总体均值 |
| 白噪声与 i.i.d. | 二阶不相关不自动独立，也不自动零条件均值 |
| 无条件方差恒定与条件方差恒定 | 平稳序列仍可有可预测的波动状态 |
| AR 系数与长期均值 | 均值 $c/(1-\phi)$ 通常不是截距 $c$ |
| AR 稳定根与状态特征值 | 滞后多项式根在圆外；状态矩阵特征值在圆内 |
| MA 平稳与可逆 | 有限 MA 总是弱平稳，可逆另需 MA 根条件 |
| ACF 与 PACF | 总关联与控制中间滞后后的额外线性关联 |
| 理论截尾与样本截尾 | 样本估计在理论零值附近仍有波动 |
| 条件 MLE 与精确 MLE | 后者包含依赖参数的初始分布 |
| 预测均值区间与未来值区间 | 未来值还包含不可预测创新 |
| 取对数与差分 | 前者改变尺度，后者改变动态累积结构 |
| 确定性趋势与单位根 | 前者围绕确定趋势，后者冲击永久进入水平 |
| DF 与普通 t 检验 | DF 原假设位于非平稳边界，参照分布改变 |
| 高相关与协整 | 协整要求 I(1) 变量的固定线性组合为 I(0) |
| 残差普通 ADF 与协整检验 | 估计残差需要专门分布校准 |
| 协整与可获利套利 | 统计长期关系不保证及时回归、市场中性或扣费后盈利 |

使用方法：遮住右列，用一句话说明区别，再举一个正文中的反例。如果只能背出公式而无法解释这里的两项区别，应返回相应章节。
