# 易错概念辨析

| 易混对象 | 应有区分 |
|---|---|
| 结构误差 / CE余项 | CE余项条件均值零由定义成立；结构误差外生需论证 |
| 总体误差 / 样本残差 | $E(xu)=0$是总体限制；$X'\hat u=0$是OLS恒等式 |
| CE / 线性投影 | 前者对所有适当函数正交；后者只对有限基函数正交 |
| 零协方差 / 零条件均值 / 独立 | 后者强于前者，逆推一般不成立 |
| 无偏 / 一致 | 固定样本量的期望中心 / 样本增长的概率集中 |
| OLS.3 / 条件同方差 | OLS.3约束二阶矩乘积；条件同方差加零条件均值是充分条件 |
| 误差正态 / 估计量渐近正态 | CLT不要求个体误差正态；精确t/F需要额外正态模型 |
| 渐近V / 回归协方差 | V是根号N缩放量的协方差，回归SE使用V/N |
| 显著 / 经济重要 | t同时受效应与精度影响，大小要结合单位 |
| 不拒绝 / 证实零 | 不拒绝可能源于低功效，应看区间和点估计 |
| p值 / 零假设概率 | p是零假设下统计量尾概率，不是P(H0为真) |
| 单独检验 / 联合检验 | 联合检验使用协方差；多个单项检验不是同一联合显著水平 |
| 均值处效应 / 平均效应 | 导数为仿射函数时可相同；一般非线性不相同 |
| log E(y\|x) / E(log y\|x) | 不可交换；log模型系数直接关联几何均值 |
| 百分点 / 相对百分比 | 出勤从80到90是10个百分点，相对增加12.5% |
| 中心化 / 新信息 | 设计空间相同；系数改为另一参考点斜率，SE可变 |
| 样本APE / 总体APE | 未知总体均值需估计时，无条件推断还计均值噪声 |
| 原始相关 / 部分相关 | 多元OVB、工具相关性要在同一控制后分析 |
| 代理相关性 / 代理充分性 | 与能力相关不保证消除目标变量的剩余能力关联 |
| 加法代理条件 / 交互代理条件 | 交互需处理额外乘积方向，课件加强为条件均值充分性 |
| 代理 / IV | 前者替代控制潜在因素，后者要避开结构误差 |
| 因变量误差 / 解释变量误差 | 前者若正交可只影响精度；后者古典误差共享复合误差而衰减 |
| 古典误差 / 记录值正交误差 | 与真值正交使Cov(x,e)=Var(e)；与记录值正交是另一假设 |
| 多元衰减 / 所有系数趋零 | 仅特定有噪变量按剩余信号衰减，其他系数方向不固定 |
| 随机工具 / 排除成立 | 随机分配不排除工具诱发其他结果通道 |
| 相关 / 强相关 / 有效 | 非零第一阶段、足够稳定识别、误差正交是不同要求 |
| 第一阶段整体F / 排除工具F | 控制可能驱动整体F，须只检验排除工具 |
| 工具数 / 秩 | 方程数够不等于独立方向够 |
| 第一阶段残差 / 结构残差 / 第二阶段残差 | 依次是d−d帽、y−Xβ帽、y−X帽β帽，不能互换 |
| 2SLS矩 / 全部样本矩为零 | 过度识别通常仅加权组合零，不是Z'残差逐项零 |
| 结构IV R² / 工具有效性 | 结构R²可负，不单独诊断有效性 |
| 稳健SE / 修复内生性 | HC只处理异方差；不修复错误矩、依赖或弱识别 |
| 稳健SE / 加权估计 | 前者不改系数；后者改变估计器并需新的合法矩条件 |
| 内生性检验 / 工具有效性检验 | 内生性检验维持工具有效；不能反过来认证工具 |
| 过度识别不拒绝 / 全部工具有效 | 工具可共同失效；恰好识别无剩余限制可检验 |
| OLS与IV排序 / 偏差方向 | 点估计排序不能确定谁更接近真值 |

典型反例：$x\in\{-1,0,1\}$，概率$(1/4,1/2,1/4)$，$u=x^2-1/2$。总体零均值零协方差成立，但条件均值不为零。用这个例子随时检查自己是否把矩条件过度解释。
