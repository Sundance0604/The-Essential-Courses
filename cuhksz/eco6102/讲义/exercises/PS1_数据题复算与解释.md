## 二、逐问解释

### (a) 出勤的基础关联

$\hat\beta_a=.0081634,se=.0022031,t\approx3.705,p\approx.000228$。控制年级后，出勤增加1个百分点与标准化期末成绩增加约.00816单位相关；增加10个百分点对应约.0816单位。不能把1个百分点说成出勤率增加1%的相对变化。

在普通SE口径下显著拒绝零斜率，但解释仍是控制年级后的关联。

### (b) 是否是因果效应

不能仅由此确信。能力、动机、对经济学的兴趣、健康或时间约束可能同时影响出勤和成绩。年级指标无法充分控制这些因素；反向反应如学生因掌握困难而更勤到课，也可能影响方向。i.i.d.抽样只支持抽样推断，不产生出勤的随机分配。

### (c) 加入priGPA与ACT

出勤系数降至.0052248，SE .0023844，$t\approx2.191,p\approx.02878$，相对(a)约下降36.0%。10个百分点约对应.0522单位。方向与原出勤系数吸收部分能力/学习习惯优势的机制相容；不能据此证明代理冗余性和充分性，或认定新系数已因果识别。

### (d) 年级指标的显著性

frosh由$p=.01248$变为$p=.64673$，显著性明显下降，系数也趋近零。soph由$p=.23208$变为$p=.07579$，证据反而增强，在10%而非5%水平显著。这一问不能笼统回答“两个虚拟变量都变得不显著”。加入代理后，年级组间先前准备差异被重新分配；两个系数的变化方向可以不同。

### (e) 加入priGPA²和ACT²

出勤系数升至.0062317，SE .0023583，$p=.00842$。检验

$$
H_0:\beta_{priGPA^2}=\beta_{ACT^2}=0,
$$

$$
F=\frac{(527.9615095-510.7891652)/2}{510.7891652/672}
=11.2961,
\quad p\approx1.496\times10^{-5}.
$$

两平方项联合显著。ACT平方单项p约.0543，并不否定联合结果；联合检验问的是整个新增空间。平方项允许代理与成绩的关系弯曲，并非改变出勤系数为非线性效应。

### (f) 出勤是否有二次非线性

在(e)中加入$a^2$，检验$H_0:\beta_{a^2}=0$。

$$
\hat\beta_{a^2}=2.873\times10^{-6},\quad
se=7.8714\times10^{-5},\quad
F=t^2\approx.0013322,\quad p\approx.970895.
$$

数据没有支持新增出勤二次项。不是证实真实关系处处线性，也不排除其他非线性。一次项此时是$a=0$处的局部斜率.0058425，SE .0109203；“一次项不显著”不能直接解释为所有出勤边际效应都为零。

### (g) 在样本均值中心化

$m=\bar a=81.7095588$。记$z=a-m$。恒等式

$$
\beta_0+\beta_1a+\beta_2a^2
=(\beta_0+\beta_1m+\beta_2m^2)
+(\beta_1+2m\beta_2)z+\beta_2z^2.
$$

所以中心化一次项

$$
\hat\alpha_1=\hat\beta_1+2m\hat\beta_2=.006312035,
\quad se(\hat\alpha_1)=.003227233,
\quad t\approx1.95587,\quad p\approx.05090.
$$

与(f)的.0058425、SE .0109203相比，它衡量平均出勤率81.71%处的斜率，不是0处斜率。由于二次模型导数为仿射函数，它也等于该样本出勤分布上的平均拟合偏效应：

$$
\frac1N\sum_i(\hat\beta_1+2\hat\beta_2a_i)=\hat\alpha_1.
$$

完整(g)回归为

$$
\begin{aligned}
\hat y={}&1.890863+.006312z+.000002873z^2\\
&-.105366frosh-.180840soph-1.524802priGPA-.112342ACT\\
&+.367912priGPA^2+.004180ACT^2.
\end{aligned}
$$

拟合值最大数值差约$2.4\times10^{-14}$，SSR、R²完全一致。中心化线性系数SE更小，是因为检验对象变为样本内参考点；没有凭空增加数据。固定$m$的方差为

$$
\operatorname{Var}(\hat\alpha_1)=\operatorname{Var}(\hat\beta_1)
+4m\operatorname{Cov}(\hat\beta_1,\hat\beta_2)+4m^2\operatorname{Var}(\hat\beta_2).
$$

普通5%双侧t参考下，p略大于.05，**不要将t先四舍五入成1.96再判显著**。此结论与(f)中平方项不显著不矛盾：检验的是不同零假设。若目标改为未知总体均值处APE的无条件推断，还需均值估计误差，见第4章；本问要求比较普通回归SE，不在此更换口径。

## 三、可复现计算（Markdown内代码）

以下核心代码仅依赖NumPy和pandas，复现系数、普通SE、SSR、F及中心化比较；不要求当前环境另装statsmodels。运行目录为课程`eco6102/`。p值可在有SciPy的环境用`t.sf`、`f.sf`复核；本次实际尾概率使用不完全Beta计算。

```python
import numpy as np
import pandas as pd

d = pd.read_csv('ATTEND.csv').astype(float)
assert len(d) == 680
used = ['stndfnl', 'atndrte', 'frosh', 'soph', 'priGPA', 'ACT']
assert not d[used].isna().any().any()
for v in ['atndrte', 'priGPA', 'ACT']:
    d[v + '2'] = d[v] ** 2
m = d.atndrte.mean()
d['ac'] = d.atndrte - m
d['ac2'] = d.ac ** 2
y = d.stndfnl.to_numpy()

def ols(names):
    X = np.column_stack([np.ones(len(d)), d[names].to_numpy()])
    b = np.linalg.lstsq(X, y, rcond=None)[0]
    u = y - X @ b
    df = len(y) - X.shape[1]
    ssr = u @ u
    # QR避免直接形成X'X再求逆。
    _, R = np.linalg.qr(X, mode='reduced')
    Ri = np.linalg.solve(R, np.eye(R.shape[0]))
    V = (ssr / df) * (Ri @ Ri.T)
    return dict(b=b, V=V, se=np.sqrt(np.diag(V)),
                ssr=ssr, df=df, fitted=X @ b)

a = ['atndrte', 'frosh', 'soph']
c = a + ['priGPA', 'ACT']
e = c + ['priGPA2', 'ACT2']
f = e + ['atndrte2']
g = ['ac', 'frosh', 'soph', 'priGPA', 'ACT',
     'priGPA2', 'ACT2', 'ac2']
fits = {k: ols(v) for k, v in dict(a=a, c=c, e=e, f=f, g=g).items()}
for k, r in fits.items():
    print(k, r['b'], r['se'], r['ssr'], r['df'])
for r, u, q in [('c', 'e', 2), ('e', 'f', 1)]:
    rr, uu = fits[r], fits[u]
    F = ((rr['ssr'] - uu['ssr']) / q) / (uu['ssr'] / uu['df'])
    print('F', r, u, F)
L = np.zeros(len(fits['f']['b']))
L[1], L[-1] = 1, 2*m
ape = L @ fits['f']['b']
ape_se = np.sqrt(L @ fits['f']['V'] @ L)
assert np.allclose([ape, ape_se],
                   [fits['g']['b'][1], fits['g']['se'][1]])
assert np.allclose(fits['f']['fitted'], fits['g']['fitted'])
```

## 四、这道题的结构

从(a)到(c)改变信息集合，从(c)到(e)改变代理的函数形式，从(e)到(f)扩展出勤函数类，从(f)到(g)仅改变参数坐标。这四种操作在经济解释、拟合空间和识别承诺上各不相同。能辨明它们，比背住某个系数更重要。
